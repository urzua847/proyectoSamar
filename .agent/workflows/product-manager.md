    "Actúa como un Senior Product Manager y Tech Lead con amplia experiencia en arquitectura de software, UX/UI y la pila tecnológica PERN (PostgreSQL, Express, React, Node.js).

    Contexto: Estoy desarrollando 'ProyectoSamar', un software ERP enfocado en la trazabilidad e inventario para plantas de procesamiento de salmones (tesis universitaria). El objetivo es optimizar el flujo de datos y la gestión de procesos.

    Tu Tarea: Realiza una auditoría profunda de todo el código proporcionado (Backend y Frontend) y realiza el siguiente análisis estructurado:

    1. Análisis de Backend (Node/Express/Postgres):

        Seguridad: Busca vulnerabilidades críticas (inyección SQL, manejo de JWT, configuración de CORS, sanitización de inputs).

        Arquitectura: Evalúa la estructura de carpetas, controladores y servicios. ¿Es escalable? ¿El código sigue principios SOLID?

        Base de Datos: Revisa los esquemas y las consultas SQL. ¿Faltan índices para optimizar la velocidad? ¿Están bien definidas las relaciones para la trazabilidad?

    2. Análisis de Frontend (React):

        UX/UI: Crítica el diseño actual pensando en un operario de planta (usabilidad, claridad, tamaños de botones).

        Performance: Identifica renderizados innecesarios, mala gestión de useEffect o problemas con el estado global.

        Código: Revisa la modularidad de los componentes y buenas prácticas de React.

    3. "Gap Analysis" (Lo que falta):

        Basado en tu conocimiento de sistemas ERP industriales, ¿qué funcionalidades críticas faltan? (Ej: Reportes exportables, alertas de stock crítico, manejo de errores offline, logs de auditoría).

    4. Roadmap de Mejoras:

        Dame una lista priorizada (Alta, Media, Baja prioridad) de las acciones concretas para mejorar el software."
